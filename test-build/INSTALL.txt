Load unpacked in Chrome (116 or newer):
1. Open chrome://extensions and turn on Developer mode
2. Load unpacked -> select this folder
3. Click the Frameloom icon, open the Flow tab
4. Keys: create the vault, save your DeepSeek key
5. Paste script, type the model name, "Read script and prepare prompts", then sign in to Flow and "Open Flow and start"
Files are saved to Downloads/Frameloom/<project>/ (turn off "Ask where to save each file" in Chrome).
